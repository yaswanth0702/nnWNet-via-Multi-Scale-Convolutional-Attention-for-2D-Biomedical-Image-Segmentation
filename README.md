# Enhancing Local Feature Modeling in nnWNet using MSCA

This project improves biomedical image segmentation by integrating a Multi-Scale Convolutional Attention (MSCA) module into the Local Scope Blocks (LSBs) of nnWNet.

The goal is to improve segmentation of thin structures and irregular boundaries in 2D biomedical images.

## Overview

Biomedical segmentation is challenging because medical images often contain:

- Thin and fragmented structures
- Irregular object boundaries
- Large scale variation
- Noise and imaging artifacts

nnWNet combines local feature modeling and global context modeling. However, its Local Scope Blocks use fixed convolution kernels, which can limit multi-scale feature extraction.

To address this, this project adds MSCA into the Local Scope Blocks to capture features at multiple receptive fields.

## Proposed Method

The proposed model is based on nnWNet with an added MSCA module.

MSCA uses parallel depthwise convolutions with different kernel sizes to capture:

- Fine details such as thin vessels
- Mid-level spatial patterns
- Larger contextual structures

The attention map generated by MSCA helps the model focus on important regions and suppress background noise.

## Datasets

The model is evaluated on:

- DRIVE dataset for retinal vessel segmentation
- ISIC-2017 dataset for skin lesion segmentation

## Implementation Details

- Framework: PyTorch
- Input size: 256 × 256
- Optimizer: Adam
- Learning rate: 1e-4
- Epochs: 50
- Loss functions:
  - Binary Cross Entropy Loss
  - Dice Loss

## Evaluation Metrics

The model is evaluated using:

- Dice Score
- Intersection over Union (IoU)
- Accuracy
- Precision
- Recall
- 95HD
- ASD

Dice and IoU measure region overlap, while 95HD and ASD evaluate boundary accuracy.

## Results Summary

The proposed nnWNet + MSCA model improves segmentation performance compared to U-Net and baseline nnWNet.

Main observations:

- Better Dice and IoU scores
- Improved boundary localization
- Better preservation of thin vessel structures
- Smoother lesion segmentation outputs
- Stable training and validation behavior
